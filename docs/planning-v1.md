## 项目定位（讨论共识）

- 研究论文助手（工作台形态，非纯对话工具）
- 长期愿景：全流程智能体（发现→筛选→阅读→笔记→复现→汇报→写作），最终替代 Zotero/Obsidian
- 分阶段做，不一次到位
- 现有工具链（Zotero/Obsidian）用得很好，先不重复造轮子

## 已确认的决策

1. 布局：侧边栏 + 顶栏（工作台形态）
2. 路由：/（对话） /papers（文库） /filter（筛选占位） /report（汇报占位） /settings（设置）
3. 文库存储：**文件夹 + SQLite 记录表**（B 方案）——PDF 落盘 + 记录 id/文件名/时间/路径，未来加元数据直接加列
4. 对话上传 PDF 与文库**各自独立**（第一版不联动）
5. 思考面板：只显示最新一轮
6. 对话页视觉：按 ui-ux-pro-max 建议（居中 800px 内容、输入框比例、消息分组）
7. 上传文件：第一版不做对话上传（先文库独立）
