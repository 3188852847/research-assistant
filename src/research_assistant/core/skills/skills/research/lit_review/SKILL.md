# 文献综述技能

## 工作流程
1. 明确综述主题和范围（时间范围、子领域）
2. 用 internet_search 检索相关论文和资料，多关键词交叉验证
3. 按主题/方法/时间线组织文献，提炼每篇的核心贡献
4. 输出结构化综述：背景 → 研究进展（分主题）→ 争议/空白 → 结论
5. 标注关键文献来源

## 输出要求
- 结构清晰，用 Markdown 标题分节
- 每节突出「已有结论 + 证据来源」
- 指出研究空白，为下一步研究提供方向
